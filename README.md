# Rest API com Spring Boot

## 📌 Sobre o projeto
API REST desenvolvida durante o curso de Spring Boot, com operações CRUD completas.

## 🚀 Tecnologias
- Java 21
- Spring Boot 3
- JPA + MySQL
- Lombok
- Dozer Mapper

## ⚙️ Endpoints
| Método | Endpoint | Descrição |
|---|---|---|
| GET | /person | Lista todos |
| GET | /person/{id} | Busca por ID |
| POST | /person | Cria novo |
| PUT | /person/{id} | Atualiza |
| DELETE | /person/{id} | Deleta |

## ▶️ Como executar
1. Clone o repositório
2. Configure o MySQL no `application.yml`
3. Execute o projeto
